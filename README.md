This repository contains an exploratory data analysis (EDA) project focusing on Netflix's movies and TV shows catalog. The analysis investigates release trends, genres, content ratings, country distributions, and runtime patterns over the years.

---

## 📊 Project Overview
* **Objective:** Uncover insights and statistical patterns within the Netflix catalog using data visualization and exploratory analysis.
* **Key Steps:**
  * Data cleaning, handling missing values, and standardizing date/duration formats.
  * Catalog growth analysis over time (movies vs. TV shows).
  * Geographical distribution of content production.
  * Genre popularity and rating classifications.
  * Interactive web dashboard deployment via **Streamlit** to filter and explore catalog metrics dynamically.

---

## 🛠️ Tech Stack & Libraries
* **Python**
* **Pandas & NumPy** (Data Aggregation & Cleaning)
* **Matplotlib & Seaborn** (Data Visualization)
* **Streamlit** (Interactive Dashboard)
